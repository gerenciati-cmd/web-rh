# Hallazgos

Problemas descubiertos mientras se trabajaba en otra cosa, fuera del alcance del plan en curso.
No se arreglan "de pasada": se documentan aquí con evidencia (plantilla `plans/_FINDING.md`) y el
usuario decide si se difieren, se planean o se descartan. `pnpm plans:status` lista los abiertos.

Nombre: `<modulo>-<slug>.md` (ej. `payroll-redondeo-uf.md`).
